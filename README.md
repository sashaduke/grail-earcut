# grail-earcut

Polygon triangulation with holes for [Grail](https://github.com/graillang/grail): a
statement-for-statement port of [mapbox/earcut.hpp](https://github.com/mapbox/earcut.hpp) 2.2.4.

```grail
use earcut;

fn main() {
    mut rings = f64[][];
    rings.push(f64[0.0, 0.0, 10.0, 0.0, 10.0, 10.0, 0.0, 10.0]); // outer ring: x0, y0, x1, y1, ...
    rings.push(f64[3.0, 3.0, 3.0, 7.0, 7.0, 7.0, 7.0, 3.0]);     // holes follow
    triangles := earcut::triangulate(&rings);                    // vertex indices, 3 per triangle
    println(triangles.len() / 3);
}
```

Vertices are numbered across all rings in order (outer ring first).

## Use

Add the package to your project's `grail.pkg`:

```
dep earcut https://github.com/sashaduke/grail-earcut
```

then `use earcut;` in your code. The module lives in `src/`.

## Verification

`tests/reference.grl` is generated by `tests/reference/earcut_cases.cpp` from the C++ library and
checks that the port returns **identical triangle lists** for ten shapes: convex and concave
polygons, one and two holes, duplicate and collinear points, a zero-area ring, a hole touching
the outer ring, and noisy polygons above 80 vertices that switch on z-order hashing.

```sh
grail test
```

The test exits non-zero if any result differs from the C++ reference.
